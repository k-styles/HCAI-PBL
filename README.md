# HCAI project hub

Coursework for Human-Centric Artificial Intelligence, SoSe 2026, TUHH.
Built on the course skeleton (`ppaamm/HCAI-PBL`).

## Running it

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open <http://127.0.0.1:8000/home/>.

## Deploying it

`render.yaml` and `build.sh` configure a free Render web service. Nothing needs
editing: `DJANGO_SECRET_KEY` is generated by Render, `DJANGO_DEBUG` is set to
`false`, and `ALLOWED_HOSTS` picks up the hostname Render provides.

Locally nothing changes — `DEBUG` defaults to on, so `runserver` still works
with no environment set up.

Two things to know about the free tier: the service sleeps after 15 minutes of
inactivity, so the first request after a pause takes about a minute; and the
disk is wiped on restart, so uploaded datasets and the run log do not persist.
Neither matters for a demo.

## Project 1 — supervised learning interface

Three pages: load a CSV, look at it, train a model on it.

The CSV is read with the header in the first row and the target in the last
column. A column that only numbers the rows is dropped, non-numeric feature
columns are dropped, and whether the problem is classification or regression is
worked out from the target — all of it reported on screen, and the problem type
can be overridden at upload.

Training follows the pipeline from lecture 1: choose a model, hold out a test
set, train once for every value of the hyperparameter, score the results. Two
details differ from the lecture's demo:

- **The hyperparameter is chosen by cross-validation inside the training rows**,
  not on the test set. The test rows are used once, after the choice is fixed.
  Selecting on the test set and then quoting that same number reports a score
  that has already been optimised against.
- **Ties are broken towards the simpler model** by default. Among values whose
  cross-validated score is within one standard error of the best, the app keeps
  the smaller tree, the larger `k`, or the stronger penalty. On the iris data,
  every tree depth from 3 to 14 scores identically in cross-validation while the
  training score climbs to 1.0 — the rule keeps depth 3.

The `Decide for me` button runs the same machinery with every choice made
automatically, for comparison. `/project1/history/` logs each run so settings can
be compared afterwards.

